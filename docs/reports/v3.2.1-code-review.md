## 1. UI 修改列表

- Logo

  - 新增裁切后的 256×256 侧边栏资源

  - 顶部只保留“工作台”，移除右侧重复页面标题和产品介绍。

  - “交付”页面标题改为“交付设置”。
- 音色流程
  - 音色分类从“保存绑定”移到“选择声音”步骤。

- 视觉与布局
  - 内容画布改为柔和浅灰绿，侧栏改为深森林色，默认按钮不再形成大块黑色。
  - 表单标签、禁用输入框和次级文字使用可读的前景/背景组合。
  - 侧栏按内容收高，页面限制最大宽度；音色绑定改为紧凑的单列任务流。
  - 浏览器在 1280 px 宽度下无横向溢出，音频上传区高度限制为 176 px。
- 图标交付
  - 新增根目录 `icon.png`（256×256）与 `icon.ico`。
  - ICO 内含 16、24、32、48、64、128、256 px 共 7 种尺寸。
  - 同步保存带版本名的品牌资产，供打包脚本或未来安装器引用。

## 3. 性能对比

以下优化对照来自同一 macOS、Python 3.9.6、Gradio 4.44.1 临时性能环境；
正式兼容性与回归测试另使用 Python 3.12 + Gradio 5.50.0 验证。

| 指标 | v3.2.0 | v3.2.1 | 变化 |
|---|---:|---:|---:|
| UI 冷启动构建（`import app`） | 1.300 s | 1.087 s | -16.4% |
| UI 构建峰值内存 | 167.4 MB | 153.2 MB | -8.5% |
| 音色页刷新（1000 个音色） | 17.492 ms | 7.986 ms | -54.3% |

优化来源：

- TTS、NumPy/SciPy 音频处理模块退出 UI 启动热路径，首次实际使用时再加载。
- 三个页面不再在构建阶段重复扫描音色目录。
- 音色分类刷新由五次目录扫描收敛为两次（分类一次、列表一次）。
