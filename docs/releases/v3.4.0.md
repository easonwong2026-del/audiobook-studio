# Audiobook Studio v3.4.0

V3 工作流稳定收口版本：从结构化剧本导入，到角色声音、Production、试听修复、导出
交付和 Studio 生命周期，形成一条可维护的本地生产路径。

## 主要变化

- 更简单的一项目一本书模型，Catalog / Bookshelf 统一项目入口。
- 更稳定的 Production 状态、总耗时展示和 Runtime 生命周期。
- 统一的 Listen & Repair 工作区，保留单段 revision / rollback。
- 更安全的 Studio start / status / stop，并支持网页直接退出 Studio。
- MCP advertised surface 收敛为 24 个核心/高级工具。

## 兼容性

No user project migration required. Existing projects remain readable; optional
storage-layout organization is still an explicit user action.
