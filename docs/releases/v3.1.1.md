# Audiobook Studio v3.1.1

**Release date:** 2026-07-25

v3.1.1 is a **release fix** for the engineering quality issues identified during the v3.1.0 release wrap-up. No new features are added.

## Fixed

- **launcher.py encoding**: Added UTF-8 encoding declaration, fixed U+FFFD replacement characters, restored Chinese comments and console output.
- **Python interpreter fallback restructured**: `AUDIOBOOK_STUDIO_PYTHON` env var (validated) → sibling `index-tts/.venv` (cross-platform) → `python`/`python3` on PATH. Clear error message when nothing is found.
- **`start.bat` simplified**: Interpreter detection centralised into `launcher.py`; `start.bat` only delegates.
- **Path safety tests restored**: `tests/qa_allowed_paths_test.py` and `qa_verify_export_safe_path.py` restored with meaningful assertions, adapted to the external data‑directory architecture, no hardcoded absolute paths.
- **Empty shell files cleaned up**: `REFACTOR_PROGRESS.md` removed (never had content); `REVIEW.md` restored with full architecture review from v3.0.
- **Single version source**: `lib/__init__.py` is the sole authoritative version (`"3.1.1"`); all runtime titles read from it dynamically.
- **README encoding fixed**: 7 U+FFFD replacement characters fixed (tree-drawing glyphs, Chinese text). App description corrected from "wiring only" to "Gradio entry point, event wiring, UI callback orchestration".
- **Project-wide encoding scan**: 16 files with U+FFFD characters flagged; critical files fixed, remaining non‑critical items tracked.
