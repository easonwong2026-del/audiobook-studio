# Audiobook Studio v3.2.0

Audiobook Studio v3.2.0 upgrades the interface from an AI audio utility into a
workflow-oriented audiobook production workbench.

## Highlights

- A five-stage production flow: Workbench, Project, Characters & Voices,
  Production & QA, and Delivery.
- Workbench status cards for the active book, chapter and segment progress,
  voice binding readiness, recent task state, and outstanding issues.
- Character voice binding is presented as four explicit steps: choose a
  character, choose a voice, preview it, and confirm the binding.
- New Audiobook Studio brand mark and launcher icon assets.

## Compatibility

- `lib.__version__` is the single runtime version source and is set to `3.2.0`.
- `structured_script.json` and `voice_bindings.json` remain compatible.
- IndexTTS2 inference, audio processing, services, repositories, and core data
  contracts are unchanged.
