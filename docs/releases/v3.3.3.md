# Audiobook Studio v3.3.3

发布日期：2026-07-29

## 版本目标

本版本处理真实书稿创建中暴露的四类问题：上传后仍需手填项目名、长篇远程 AI
响应截断、模型 ID 依赖记忆输入，以及创建失败后同名残留目录不可见。既有
`structured_script.json` 正式项目格式、v2 读取兼容、声音绑定、TTS、队列和导出
协议均未修改。

## 自动项目名

- TXT、DOCX、EPUB 和高级 JSON 导入均读取上传对象的原始文件名，而不是 Gradio
  临时目录名。
- 去掉最后一个扩展名并使用统一安全名称函数；中文、英文、数字、空格、连字符、
  下划线和多点版本名可保留。
- 只填充空的项目名/作品名，不覆盖用户修改。
- 上传或编辑名称时即时显示 `available`、`valid`、`incomplete`、`corrupted`、
  `temporary` 或 `legacy` 状态。

## AI 长文本与输出协议

- 默认单批上限为 12,000 字符，可通过
  `AUDIOBOOK_STUDIO_AI_MAX_INPUT_CHARS` 覆盖。
- 优先按章节切分；长章节按自然段，再按 `。！？；` 及句末闭合符号切分。
- 每批使用 `audiobook-script-batch-v3.1`，携带批次、章节和分片信息，只返回
  当前批次的 `segments`。同章分片按原顺序合并，不生成重复章节。
- 本地验证 schema、batch ID、章节 ID/标题、非空 Segment、枚举、数值范围、
  停顿位置、重复批次、解释性前缀和明显原文覆盖差异。

## 截断识别与有界恢复

- DeepSeek 的 `finish_reason=length` 和 OpenAI Responses 的 incomplete 状态会抛出
  专用截断异常。
- 空成功响应、`Unterminated string` 和明显发生在 JSON 末尾的解析错误也按截断
  处理，不使用字符串拼接伪造 JSON。
- 只拆小失败的当前批次，最多递归 3 层；无法继续拆分的叶片最多请求 2 次。
  已成功批次不会重发，任一批最终失败则不会调用正式项目创建。
- UI 进度覆盖读取、名称检查、分批、AI 批次/重试、结构校验和原子创建六个阶段。

## 模型发现

- 模型字段为 `allow_custom_value=True` 的可编辑 Dropdown。
- Local 返回固定离线选项；OpenAI/DeepSeek 使用当前表单 Base URL 的 `/models`。
- 当前表单 API Key 优先，空值回退 Keyring 或环境变量；ID 去重排序。
- 刷新失败保留当前选择。连接测试同时报告 Provider、模型列表和当前模型可见性；
  隐藏模型列表的兼容服务只显示警告，不阻止保存自定义模型。
- Provider 默认模型只由 Provider 类维护。

## 残留项目恢复

- `ProjectRepository.inspect_project_slot()` 对工作区和 Legacy 目录执行结构化检查。
- 新建页可显式“清理残留并重试”；设置页可刷新异常项目、打开目录或移动到回收站。
- 归档位置为 `<data_dir>/.trash/projects/<name>_<timestamp>`，冲突时增加随机后缀，
  优先同磁盘原子移动。
- 归档不会自动重启 AI 请求，也不能处理合法项目或 Legacy 项目。正式项目删除仍走
  原有管理流程。

## 数据安全

- API Key 继续只保存到系统 Keyring 或由环境变量提供。
- 日志和错误摘要不包含 API Key、完整原文或完整 Provider 原始响应。
- 创建仍采用临时剧本文件与最终目录原子替换；失败时不占用正式项目名。
- 残留操作是可恢复移动，不是永久删除，且必须由用户明确点击。

## 验收

自动化覆盖文件名派生、槽位状态与归档、厂商截断识别、当前批次拆分、协议验证、
部分成功不落盘、模型列表优先级/去重及既有 UI 接线。CI 不发送真实 OpenAI 或
DeepSeek 请求，也不加载 IndexTTS2/GPU。

手工验收清单：

1. 上传中文、多点文件名并确认自动填写后仍可手改。
2. 使用真实长书稿观察批次及重试进度，确认最终章节顺序。
3. 使用 OpenAI、DeepSeek 及自定义兼容 Base URL 刷新模型并测试连接。
4. 制造缺失文件和损坏 JSON 目录，确认新建页/设置页可见且归档后名称恢复可用。
5. 确认失败后书稿、名称、作品名和作者仍留在表单。

## 已知限制

- 不提供跨进程 AI 批次断点续传；同一次创建内会避免重复成功批次。
- `/models` 依赖服务端兼容实现；隐藏模型列表时需要保留自定义模型 ID 后直接尝试。
- 自动原文覆盖检查用于阻止明显丢失/补写，不能替代人工导演校对。
- CI 不覆盖真实网络限流、供应商账户权限、Windows Keyring、GPU 和完整长篇付费调用。

## 回滚

代码可回滚到 v3.3.2；项目正式格式未升级，无需数据迁移。已归档残留仍保存在
`.trash/projects`，可由用户手工移回。回滚不会影响既有项目、声音绑定或合成产物。
