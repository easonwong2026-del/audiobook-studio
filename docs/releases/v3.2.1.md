# Audiobook Studio v3.2.1（验收修正版）

v3.2.1 是 v3.2.0 UI/UX 重构的 release-hardening 版本。它不增加 TTS
核心能力，不改变 IndexTTS2 推理逻辑，也不改变现有 JSON 数据协议。

## Fixed

- 统一运行时版本显示与 v3.2.0 发布文档；`lib.__version__` 仍是唯一版本来源。
- 角色声音配置明确为“选择角色 → 选择声音 → 试听 → 确认绑定”，试听会使用当前候选音频。
- “生产与质检”新增内部阶段导航：合成中心、试听质检、角色补录。
- 进入生产阶段时显示剧本有效性和未绑定角色提示，但不阻断用户查看和质检。
- 项目创建页提供 `structured_script.json` 示例下载。
- 将质量参数 1/2/3 显示为快速/标准/高质量，内部值保持兼容。
- 动态显示项目默认导出目录，规范化 Windows 数据目录路径，并统一角色描述格式。

## Compatibility

- `structured_script.json` 与 `voice_bindings.json` 格式兼容。
- services、repositories、IndexTTS2 推理、音频处理和核心数据协议保持不变。
- 完成 WorkBuddy Windows + IndexTTS2 第二轮真实验收后，再创建正式 v3.2.0 发布标签。
