# Audiobook Studio v3.1.0

> **Audiobook Studio** — a local audiobook synthesis workbench powered by Gradio and IndexTTS2.

## Version positioning

V3.1 is a **stabilisation release** that modularises the codebase, adds a structured persistence layer, introduces supplement (per-role re-synthesis), and achieves **399 passing tests** with **zero GPU/model at test time**. It is the first release with a CI pipeline, a single-version-source convention, and a complete CHANGELOG.

The project is designed as a **lightweight workbench frontend** for IndexTTS2. It does **not** bundle any model weights, torch, CUDA, or FFmpeg runtimes. All of those remain external dependencies managed by the user.

---

## Major new features

| Feature | Description |
|---------|-------------|
| **Supplement synthesis** | Re-synthesise lines for a single role after the main pass — no need to re-run the entire book. |
| **Pause / resume & resumable synthesis** | Cancel and pick up where you left off mid-book. |
| **Audio loudness normalisation** | LUFS-16 post-processing for consistent volume across chapters. |
| **Export subtitles** | `.srt` / `.vtt` chapter markers alongside audio export. |
| **Data-directory externalisation** | All projects, audio output, voice library and exports live outside the repo (default `~/AudiobookStudio/`); configurable via env-var, JSON config, or in-app panel. |

---

### What's NOT included

This repository ships only the **application source code**. You must provide:

- **IndexTTS2** — with all required model checkpoints
- **A Python 3.10 environment** — ideally the venv supplied with IndexTTS2
- **FFmpeg** — system binary for MP3/M4B export
- **CUDA-capable GPU** — 12 GB+ VRAM recommended

**No Windows installer, no AppImage, no Docker image** is provided.
