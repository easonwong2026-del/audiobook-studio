# Audiobook Studio v3.3.1

发布日期：2026-07-28

## 版本定位

v3.3.1 将项目收口为“AI 驱动的本地有声书制作工作台”：统一原稿创建、AI
导演、人工校正、本地 IndexTTS2 生产、质检和导出流程，并补齐可诊断、可验收、
可回滚的稳定发布能力。

## 新功能

- TXT、DOCX、EPUB 原稿直接进入 AI 剧本导演并创建项目。
- OpenAI、DeepSeek、Local Provider 设置与状态加载。
- API Key 通过系统 Keyring 保存，支持清除和来源状态；不写入配置、日志或报告。
- 导演试听、反馈调整和 v3 精确停顿进入正式合成。
- 设置页环境诊断及可复制 Markdown 报告。
- 参数化验收脚本和长篇剧本一致性检查。

## 修复内容

- 原子项目创建，异常时清理临时目录。
- 项目扫描跳过不完整项目和 `.tmp_` 残留目录。
- AI 设置错误信息脱敏。
- 文档不再把 structured_script.json 描述为唯一入口。

## 升级说明

1. 备份当前数据目录。
2. 更新代码并确认 `requirements.txt` 仍使用 `gradio>=5.50,<6`。
3. 在原 IndexTTS2 虚拟环境中安装工作台依赖；不要把 Torch、CUDA、模型复制进仓库。
4. 启动后在“设置 → 系统信息”运行环境诊断。
5. 打开一个既有 v2 项目，确认项目、绑定和已合成段落可读。

`structured_script.json` 核心字段和 v2 项目兼容路径没有改变。

## 已知限制

- 不提供 IndexTTS2、Torch、CUDA、模型或 GPU 驱动安装。
- macOS / Linux 可运行诊断和工作台，但主验收平台仍为 Windows 10 / 11。
- CI 不运行真实 GPU 推理、付费 Provider 请求或整书合成。
- 疑似角色别名只提示候选，不自动修改或合并。

## 回滚方法

1. 停止工作台并备份数据目录。
2. 将代码切回上一稳定 tag/commit；不要删除或覆盖数据目录。
3. 使用原虚拟环境依赖启动。
4. 若新项目需要回退，完整保留其项目目录，再用上一版本只读检查；不要手工改写
   `structured_script.json` 或 `project.json`。

## 数据目录说明

默认数据目录为 `~/AudiobookStudio`，可通过设置页或
`AUDIOBOOK_STUDIO_DATA_DIR` 覆盖。项目位于 `<数据目录>/projects`，音色库位于
`<数据目录>/voice_library`，试听与任务缓存位于 `<数据目录>/preview`。
升级和回滚均不应移动、删除或提交这些用户数据。
