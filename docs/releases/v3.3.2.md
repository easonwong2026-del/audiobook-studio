# Audiobook Studio v3.3.2

发布日期：2026-07-29

## 修复内容

- 启动器统一检查 `gradio`、`numpy`、`scipy`、`pyloudnorm`、`mutagen` 和 `keyring`，缺失时使用最终解析的 Python 执行 `python -m pip install -r requirements.txt`。
- 修复设置页错误地位于主工作区之外导致内容只显示一半的问题。
- 删除“角色与声音”页面的导演试听、试听反馈和应用反馈接线。
- 将确认绑定调整为当前参考音频旁的正常底部操作区，避免巨大竖向按钮和中等窗口溢出。

## 页面结构调整

设置页与工作台、项目管理、角色与声音等页面共同位于 `main-area` 内，通过现有 `_goto("settings")` 导航控制显示。设置页增加专用 class、完整宽度约束、Tabs 容器约束和诊断表格内部滚动。

## API Key 安全说明

API Key 仍只写入系统 Keyring；配置文件不保存密钥，界面不回填完整密钥，日志和错误提示不包含密钥。Keyring 不可用时提示可操作的后端或环境变量方案。

## 删除的导演试听功能

角色与声音页不再包含导演试听 Accordion、试听播放器、试听状态、反馈下拉框或应用反馈按钮。生产与质检页面原有的 Segment 重生成能力不变。

## 响应式布局验证

新增 1180px 中等窗口断点，收缩侧栏和主区域内边距，使表单、操作按钮、设置 Tabs 和诊断表格允许换行且不撑破页面。

## 自动化测试结果

发布前运行 `python3 -m pytest -q`、关键设置/接线/工作流/环境诊断测试以及 `git diff --check`。

## 手工验收结果

已完成静态结构和应用构建回归检查；实际浏览器验收需在具备 IndexTTS2 推理环境的用户机器上按 1440px、1280px、1024px 和 900px 窗口复核。

## 未修改的核心业务范围

未修改剧本 JSON 协议、角色绑定格式、音色库目录格式、IndexTTS2 推理、合成队列或导出协议。

## 风险与回滚方式

本版本只涉及启动依赖、UI 容器/接线和只读诊断；如需回滚，恢复到 v3.3.1 或回退本 PR 提交即可。
