# Audiobook Studio v4.0.0

v4.0.0 引入 source-first 项目架构：原文由本地不可变保存，语义片段只引用坐标，AI 仅路由 speaker，TTS plan 独立拆并文本，runtime.db 事务保存任务与缓存状态。

新书默认创建 v4 项目。原 v3 项目和页面继续可用，并提供 copy-only 迁移：迁移前完整备份，重建 source 时明确标注 fidelity，不覆盖旧项目。

IndexTTS2 使用常驻、签名感知 adapter 和 RTX 5070 Ti Laptop 12GB provisional profile。真实目标机 SHA、签名、VRAM 和音质 benchmark 仍须按 `docs/v4/indextts-runtime-audit.md` 完成。
