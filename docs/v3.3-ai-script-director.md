# 1. v3.3 核心设计理念

## 不做简单文本切割

禁止按照以下方式机械拆分：

- 标点
- 句号
- 行数
- 字数

例如：

错误：

```text
他说：
"你为什么回来？"
```

拆成：

```text
他说：
你为什么回来？
```

导致两个不同语气。

正确：

保持完整语义单元：

```yaml
speaker: 张三
text: 他说："你为什么回来？"
emotion: 疑惑
delivery: slow_question
```

---

# 2. 剧本分析原则

## 2.1 最小语义单元

AI 分析单位不是句子，而是：

> 一个自然讲话动作

判断标准：

保持以下要素一致，才作为一个 segment：

- 同一人物
- 同一情绪
- 同一语境
- 同一表达目的

例如：

原文：

```text
李云龙走过去。

他看着敌人说道：

"你们几个，还不够资格让我害怕。"
```

不要：

```yaml
segment1:
  李云龙走过去。

segment2:
  他说...

segment3:
  你们几个...
```

应该：

```yaml
segment1:
  speaker: 旁白
  text: 李云龙走过去。
  pause: 800ms

segment2:
  speaker: 李云龙
  text: 他说："你们几个，还不够资格让我害怕。"
  emotion: confident
  speed: 0.95
  pause_before: 500ms
  pause_after: 1000ms
```

---

# 3. 情绪连续性设计

## 禁止频繁切换情绪

同一个人物连续讲话时，默认继承上一情绪。

例如：

```text
"你来了。"

"我等你很久了。"

"但是现在已经晚了。"
```

不要：

```text
neutral

happy

angry
```

应该保持：

```yaml
emotion: cold
```

只有明显变化才切换。

例如：

```text
平静讲话
↓
突然愤怒
↓
沉默
```

此时才创建新的 emotion segment。

---

# 4. 声音节奏设计

新增 delivery metadata。

## 速度 speed

范围：

```text
0.85 - 1.15
```

原则：

禁止连续出现：

```text
1.3
0.8
1.4
```

避免导致机械跳动。

推荐：

正常：

```text
1.0
```

紧张：

```text
1.05
```

激动：

```text
1.1
```

沉重：

```text
0.9
```

---

# 5. 轻重缓急

增加：

```json
"intensity"
```

范围：

```text
0 - 1
```

例如：

普通：

```json
{
  "intensity": 0.4
}
```

强调：

```json
{
  "intensity": 0.8
}
```

不要整段使用最高强度。

---

# 6. 停顿与留白系统

有声书质量的关键是停顿与留白。

增加 pause metadata。

## 短停顿

```text
pause_short

300-500ms
```

场景：

逗号。

## 思考停顿

```text
pause_think

800-1500ms
```

场景：

- 犹豫
- 沉默

## 戏剧停顿

```text
pause_drama

1500-3000ms
```

场景：

重大转折。

---

# 7. 空白控制机制

不要通过大量切 segment 实现停顿。

增加特殊标记。

例如：

文本：

```text
我知道……

但是我必须这么做。
```

转换：

```json
{
  "text": "我知道[break:1200ms]但是我必须这么做"
}
```

或者：

```json
{
  "pauses": [
    {
      "position": 3,
      "duration": 1200
    }
  ]
}
```

---

# 8. 呼吸感设计

增加 breath metadata。

例如：

```json
{
  "breath": "light"
}
```

类型：

```text
none
light
normal
heavy
```

应用：

- 长句
- 激烈对白
- 情绪变化

# 9. structured_script.json v3

新的格式：

```json
{
  "version": "3.0",
  "chapter": "第一章",
  "segments": [
    {
      "id": 1,
      "speaker": "李云龙",
      "text": "你们几个，还不够资格让我害怕。",
      "emotion": "confident",
      "emotion_strength": 0.7,
      "delivery": {
        "speed": 0.95,
        "pitch": -2,
        "intensity": 0.8,
        "breath": "normal"
      },
      "pause_before": 500,
      "pause_after": 1200
    }
  ]
}
```

# 产品定位

v3.3 不再定义为 **AI Script Parser**，而是：

> **AI Script Director（AI 剧本导演）**

项目方向更接近：

```text
ElevenLabs Studio
+
Adobe Podcast
+
AI 小说导演
```

核心变化是建立 TTS 前的“导演层”，将产品从文本切割和机械朗读工具升级为具备角色、情绪、节奏、停顿与呼吸设计能力的有声书制作工作台。
